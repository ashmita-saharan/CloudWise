# Sources and attribution

The scaffold was designed from the provided **CloudWise — Python + SimPy Implementation Guide** (CCSA BCS 304, Python + SimPy edition), especially its sections on architecture, folder layout, algorithms, metrics, workload scenarios, API result contract and phased build order. A copy is in this folder for local reference.

External documentation recommended by that guide:

- [SimPy documentation](https://simpy.readthedocs.io/en/stable/): event/process/environment/resource semantics.
- [SimPy examples](https://simpy.readthedocs.io/en/stable/examples/): example simulation patterns.
- [FastAPI documentation](https://fastapi.tiangolo.com/): HTTP endpoint and request model patterns.
- [React documentation](https://react.dev/): component and state patterns.
- [Vite documentation](https://vite.dev/guide/): frontend tooling.
- [Recharts documentation](https://recharts.org/): charts from simulation output.
- [CloudSimPy repository](https://github.com/FC-Li/CloudSimPy): **architecture inspiration only**; no code copied or dependency taken.

The Python model, policy, API, frontend, and tests in this starter are freshly written for CloudWise. Consult each dependency's own licence before distribution.
